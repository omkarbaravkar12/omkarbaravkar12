## 🚀 Featured Projects

<details>
<summary><b>⚡ DSA Visualizer — Algorithm Execution Platform</b></summary>
<br>

A full-stack DSA visualization platform built entirely on Java Servlets and JDBC — no Spring, no Hibernate. Users can step through sorting, searching, and graph algorithms in real time through a vanilla-JS frontend powered by REST-style API endpoints.

| Attribute | Detail |
|---|---|
| **Stack** | Java · Servlets · JDBC · PostgreSQL · Apache Tomcat · Apache Ant · Vanilla JS |
| **Architecture** | WAR deployment, REST-style endpoints, framework-independent |
| **Security** | Secure user authentication, HTTP session management |
| **Features** | Algorithm execution-history tracking, step-by-step real-time rendering |
| **Build** | Automated WAR build pipeline via Apache Ant |
| **Origin** | Refactored from a Spring Boot prototype to a lightweight Servlet app |
| **Repository** | [github.com/omkarbaravkar](https://github.com/omkarbaravkar) |

This project was an exercise in owning the full stack without a framework crutch — every request lifecycle, session token, and JDBC transaction is written and managed manually.

</details>

<details>
<summary><b>🏫 Smart Student ERP System — Multi-Module Enterprise Platform</b></summary>
<br>

A full-stack Student ERP covering authentication, academics, finance, library, and communication — built with a raw Java HTTP backend and a vanilla JS frontend. The system supports role-based access control with dynamic sidebar rendering per user role.

| Attribute | Detail |
|---|---|
| **Stack** | Java · PostgreSQL · JDBC · HTML / CSS / JavaScript |
| **Database** | Normalised PostgreSQL schema across 5 domains: auth, academic, finance, library, communication |
| **Security** | Session-based login, role-based access control (RBAC) |
| **Frontend** | Vanilla JS, dynamic sidebar per user role |
| **Deployment** | Backend on port 8080 + static frontend, all CORS and routing resolved |
| **Repository** | [github.com/omkarbaravkar](https://github.com/omkarbaravkar) |

Designed to demonstrate enterprise-grade thinking at a student scale — domain-separated schemas, fine-grained access control, and clean frontend-backend integration without any external dependency.

</details>
